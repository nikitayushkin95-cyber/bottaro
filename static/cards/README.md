# Изображения карт

В этой директории должны находиться изображения карт:

- `card_back.png` - рубашка карты (200x300px)
- `the_fool.png` - карта Дурак
- `the_magician.png` - карта Маг
- `the_high_priestess.png` - карта Жрица
- `the_empress.png` - карта Императрица
- `the_emperor.png` - карта Император
- `the_hierophant.png` - карта Иерофант

Для полноценной работы WebApp добавьте PNG изображения карт размером примерно 200x300 пикселей.

## Создание изображений

Вы можете:
1. Использовать изображения из колоды Rider-Waite
2. Создать собственные изображения
3. Использовать AI для генерации изображений карт

## Формат файлов

- Формат: PNG
- Размер: 200x300 пикселей
- Фон: прозрачный или темный
- Качество: высокое для четкого отображения
